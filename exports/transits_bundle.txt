# Astra Transit Engine (Gochara System) Export Guide

Welcome to the **Astra Transit System** export bundle. This package contains all the essential files needed to understand, calculate, and visually display astrological transits (*Gochara*—the real-time movement of planets through the sky relative to a birth chart).

## 1. What is a Transit? (The Simple Intuition)

Think of a natal birth chart as the **architectural blueprint of a house**. It never changes. 
A **transit** (*Gochara*, meaning "planetary movement" or "cow pasture path") is like the **daily weather** moving across that house. When a storm or bright sunshine passes directly over a sensitive room (like the roof or the front door), you feel the effects immediately.

In this system, we track how transiting planets cross over the exact positions of your birth planets.

## 4. Key Concepts & Classical Phaladeepika Principles

### A. Planetary Speeds & Stations (*Stambhana*)
When planets appear to stop and reverse direction from Earth's point of view:
- **Stationary Retrograde (`SR` / *Vakra-ārambha*):** The planet slows to a halt and begins moving backward. In the chart, it is marked with a bold crimson **`SR`** label and a dashed red halo.
- **Stationary Direct (`SD` / *Vakra-tyāga*):** The planet finishes its backward motion, halts, and starts moving forward again. It is marked with a green **`SD`** label.
- **Threshold:** A planet is considered stationary when its speed drops to **10% or less** of its normal average speed. Mercury and Venus use an acceleration-bounded $\pm 12\text{h}$ window to prevent false multi-day stationarity.

### B. The 4 Milestone Tiers
Instead of scrubbing through 365 days one by one, the [`milestone_scanner.py`](file:///Users/hajnaljanos/PycharmProjects/astra/exports/transits/engine/milestone_scanner.py) finds key events automatically:
1. **`NATAL_STATION` (Tier 1 - Critical):** A planet halts directly on top of (or in a classical glance to) one of your birth planets within a tight **3°20'** window (a *Navamsha orb*).
2. **`EXACT_ASPECT` (Tier 2 - High):** A planet (Mars, Jupiter, Saturn, Rahu, Ketu, Sun, Venus, Mercury) reaches exact `0°00'` alignment with a natal planet. It tracks retrograde loops (`Pass 1`, `Pass 2`, `Pass 3`), accounting for boundary offsets.
3. **`SKY_STATION` (Tier 3 - Medium):** A general direction change anywhere in the zodiac.
4. **`SIGN_INGRESS` (Tier 3 - Medium):** A planet crosses the boundary into a new zodiac sign (`0°00'` direct, `29°59'` retrograde), updating whole-sign house topics.

### C. Classical Moon-Gochara House Favorability
Per *Phaladeepika* Chapter 26, transits are evaluated primarily from the **Natal Moon (*Janma Rasi*)**:
- **Malefics (Sun, Mars, Saturn, Rahu, Ketu)**: Favorable in **Upachaya houses (3, 6, 11)** from the Moon, conferring victory and tangible gains.
- **Benefics (Jupiter, Venus, Mercury, waxing Moon)**: Auspicious in cardinal (*Kendra*) and trine (*Trikona*) houses.
- Each planet in the transit payload carries an `is_favorable_from_moon` boolean readout.

### D. The Bi-Wheel Chart Visuals
- **Inner Ring:** Your permanent birth chart (*D1 Natal*).
- **Outer Ring:** The moving transit planets on that date.
- **Aspect Lines:** Lines connecting outer transit planets to inner birth planets:
  - **Solid Lines:** *Applying* aspects (the transit planet is moving closer to exact alignment—energy is building up).
  - **Dashed Lines:** *Separating* aspects (the transit planet is moving away—the peak moment has passed).
- **Diamond Rim Pins:** Small clickable diamond markers on the outer circle showing upcoming planetary stations. Clicking one instantly jumps the chart to that exact date and time in the chart's local timezone.

## 3. Planetary Speed, Station States (*Gati* / *Stambhana*), & Transit Physics
The speed of a transiting body determines the psychological depth and enduring impact of its transit.

### Mean Daily Longitudinal Speeds (degrees / day):
* **Sun**: `0.9856°/day`
* **Moon**: `13.1764°/day`
* **Mars**: `0.5240°/day`
* **Mercury**: `1.0000°/day` (mean orbital longitude ~0.9856° solar-locked, 1.0° baseline)
* **Jupiter**: `0.0831°/day`
* **Venus**: `1.0000°/day` (1.0° baseline)
* **Saturn**: `0.0335°/day`
* **Rahu / Ketu**: `0.0530°/day` (mean true node oscillation baseline)

### Station States & Classical Motion Classifications (*Gati*):
* **Stationary Threshold (`is_stationary`)**:
  * Applies to the 5 star planets: Mars, Mercury, Jupiter, Venus, Saturn.
  * A planet is defined as stationary when its relative speed ratio `abs(daily_speed) / mean_daily_speed <= 0.10` (moving at $\le 10\%$ of normal daily motion).
  * Fast planets (Mercury and Venus) utilize an acceleration-bounded $\pm 12\text{h}$ direction change window ($d(\text{speed})/dt$) with `speed_ratio <= 0.25` to prevent multi-day false stationarity.
  * Slow outer planets (Mars, Jupiter, Saturn) utilize a $\pm 48\text{h}$ direction reversal root search.
* **Stationary Retrograde (`SR` / *Vakra-ārambha / Stambhana*)**:
  * The planet slows to a halt while transitioning from direct (positive) to retrograde (negative) motion ($d(\text{speed})/dt < 0$).
* **Stationary Direct (`SD` / *Vakra-tyāga / Stambhana*)**:
  * The planet halts while transitioning from retrograde (negative) to direct (positive) motion ($d(\text{speed})/dt > 0$).
* **Slow (*Mandatara*)**:
  * Motion where `0.10 < speed_ratio <= 0.50`.
* **Retrograde (*Vakri*)**:
  * Planetary longitudinal speed is negative (`daily_speed < 0`) and `speed_ratio > 0.10`.
* **Accelerated / Fast (*Atichara*)**:
  * Motion exceeding typical bounds (`speed_ratio >= 1.20`).
* **Direct / Normal (*Rju*)**:
  * Standard forward motion (`speed_ratio > 0.50` and positive).

## 4. Transit Milestone Scanner Architecture (Coarse-to-Fine Ephemeris Scan)

3. **Four Milestone Event Tiers**:
   * **`NATAL_STATION` (Tier 1 - Critical)**: A planet crosses `daily_speed == 0.0` (`SR` or `SD`) while within $3^\circ 20'$ (Navamsha orb) of a conjunction or classical Graha Drishti to a natal planet or natal Lagna.

Tagged with pass number (`Pass 1`, `Pass 2`, `Pass 3`) across retrograde loops, accounting for loop entry offsets.

4. **Output Integrity**: Pure dictionary conforming to Hemisphere A rules (floats, ints, booleans, strings; zero HTML, zero CSS styling).

def annular_sector(r_in, r_out, a_start, a_end):
    rad_s = math.radians(a_start)
    rad_e = math.radians(a_end)
    x1_in = r_in * math.cos(rad_s)
    y1_in = r_in * math.sin(rad_s)
    x2_in = r_in * math.cos(rad_e)
    y2_in = r_in * math.sin(rad_e)
    x1_out = r_out * math.cos(rad_s)
    y1_out = r_out * math.sin(rad_s)
    x2_out = r_out * math.cos(rad_e)
    y2_out = r_out * math.sin(rad_e)
    large_arc = 1 if ((a_end - a_start) % 360) > 180 else 0
    return (
        f"M {x1_in:.2f} {y1_in:.2f} "
        f"L {x1_out:.2f} {y1_out:.2f} "
        f"A {r_out:.2f} {r_out:.2f} 0 {large_arc} 1 {x2_out:.2f} {y2_out:.2f} "
        f"L {x2_in:.2f} {y2_in:.2f} "
        f"A {r_in:.2f} {r_in:.2f} 0 {large_arc} 0 {x1_in:.2f} {y1_in:.2f} Z"
    )

def get_nakshatra_abbreviation(name: str, length: int = 4) -> str:
    if not name:
        return ""
    clean = re.sub(r"[^a-zA-Z]", "", name)
    return clean[:length].capitalize()

def relax_planet_angles(planets, has_ascendant_barrier=True, is_outer=False):
    if not planets:
        return
    min_dist = 8.5 if not is_outer else 8.0
    planets_sorted = sorted(planets, key=lambda p: p["true_angle"])
    n = len(planets_sorted)
    angles = [p["true_angle"] for p in planets_sorted]
    for _ in range(35):
        for i in range(n):
            j = (i + 1) % n
            diff = (angles[j] - angles[i]) % 360.0
            if diff < min_dist:
                overlap = min_dist - diff
                angles[i] = (angles[i] - overlap * 0.5) % 360.0
                angles[j] = (angles[j] + overlap * 0.5) % 360.0
    for i, p in enumerate(planets_sorted):
        p["draw_angle"] = angles[i]

"""

3. SKY_STATION (Tier 3 - Medium): Stationary Retrograde (SR) / Direct (SD) pivots in the sky.
4. SIGN_INGRESS (Tier 3 - Medium): Major slow planet crossing 0°00' into a new Tropical sign.

Strictly adheres to Hemisphere A (pure mathematical calculus; zero HTML, zero CSS).
"""

def _get_planet_lon_and_speed(jd: float, p_name: str) -> Tuple[float, float]:
    """Returns (longitude_deg_0_360, daily_speed_deg_per_day) for a planet at Julian Day."""
    if p_name in ["Rahu", "Ketu"]:
        # True node for Kala methodology
        res = swe.calc_ut(jd, swe.TRUE_NODE)
        rahu_lon = res[0][0] % 360.0
        rahu_speed = res[0][3]
        if p_name == "Rahu":
            return rahu_lon, rahu_speed
        else:
            return (rahu_lon + 180.0) % 360.0, rahu_speed
    else:
        pid = SWE_PLANET_MAP.get(p_name, swe.MARS)
        res = swe.calc_ut(jd, pid)
        return res[0][0] % 360.0, res[0][3]


def _revjul_to_dict(jd: float, timezone_hours: float = 0.0) -> Dict[str, Any]:
    """
    Converts Julian Day (in UT) to localized date parts for UI jump and display,
    adding half a minute (0.5 / 1440.0) so Swiss Ephemeris natively handles all
    minute, hour, day, month, and leap-year rollovers without overflow bugs.
    """
    local_jd = jd + (timezone_hours / 24.0) + (0.5 / 1440.0)
    y, m, d, float_hour = swe.revjul(local_jd)
    hour = int(float_hour)
    minute = int((float_hour - hour) * 60.0)
    day = int(d)

    # Also record exact UTC timestamp
    utc_jd = jd + (0.5 / 1440.0)
    uy, um, ud, u_float_h = swe.revjul(utc_jd)
    u_hour = int(u_float_h)
    u_min = int((u_float_h - u_hour) * 60.0)

    tz_sign = "+" if timezone_hours >= 0 else "-"
    abs_tz = abs(timezone_hours)
    tz_h = int(abs_tz)
    tz_m = int(round((abs_tz - tz_h) * 60.0))
    tz_suffix = f"{tz_sign}{tz_h:02d}:{tz_m:02d}"

    return {
        "year": int(y),
        "month": int(m),
        "day": day,
        "hour": hour,
        "minute": minute,
        "timestamp_utc": f"{int(uy):04d}-{int(um):02d}-{int(ud):02d}T{u_hour:02d}:{u_min:02d}:00Z",
        "timestamp_local": f"{int(y):04d}-{int(m):02d}-{day:02d}T{hour:02d}:{minute:02d}:00{tz_suffix}",
        "formatted_date": f"{day:02d}/{int(m):02d}/{int(y):04d}",
        "jump_date": f"{int(y):04d}-{int(m):02d}-{day:02d}",
        "jump_time": f"{hour:02d}:{minute:02d}:00"
    }


def _get_candidate_aspects(planet: str) -> List[Tuple[str, float]]:
    """Returns nominal glance angles for a given planet."""
    aspects = [("Conjunction", 0.0), ("7th Opposition", 180.0)]
    if planet == "Mars":
        aspects.extend([("4th Aspect", 90.0), ("8th Aspect", 210.0)])
    elif planet in ["Jupiter", "Rahu", "Ketu"]:
        aspects.extend([("5th Trine Aspect", 120.0), ("9th Trine Aspect", 240.0)])
    elif planet in ["Sun", "Venus", "Mercury"]:
        aspects.extend([("5th Trine Glance", 120.0), ("9th Trine Glance", 240.0)])
    elif planet == "Saturn":
        aspects.extend([("3rd Aspect", 60.0), ("10th Aspect", 270.0)])
    return aspects


def scan_transit_milestones(
    natal_chart: Dict[str, Any],
    start_year: int,
    start_month: int,
    start_day: int,
    start_hour: int = 12,
    start_minute: int = 0,
    days_back: int = 90,
    days_forward: int = 270,
    transit_latitude: float = 51.5074,
    transit_longitude: float = -0.1278,
    transit_timezone: float = 0.0,
    nakshatra_system: str = "ERNST_DHRUVA",
    aspect_orb_degrees: float = 3.3333
) -> Dict[str, Any]:
    """
    Scans a configurable date window around the target transit date and identifies:
    - NATAL_STATION: Planetary stations within 3°20' of natal planets or Lagna
    - EXACT_ASPECT: 0°00' exact degree aspect hits tagged with retrograde loop passes
    - SKY_STATION: General planetary stations in the sky
    - SIGN_INGRESS: Slow planet sign ingress into 0°00' of a new Tropical sign
    """
    # 1. Extract Natal Targets (Grahas + Lagna)
    natal_d1 = natal_chart.get("vargas", {}).get("D1", {})
    natal_grahas = natal_d1.get("grahas", {})
    natal_lagna = natal_d1.get("lagna", {})

    natal_targets = {}
    for p_name, g in natal_grahas.items():
        natal_targets[p_name] = g.get("longitude", 0.0)
    if natal_lagna:
        natal_targets["Lagna"] = natal_lagna.get("longitude", 0.0)

    natal_lagna_sign = natal_lagna.get("sign", "Aries")
    natal_lagna_idx = SIGNS_LIST.index(natal_lagna_sign) if natal_lagna_sign in SIGNS_LIST else 0
    natal_moon_sign = natal_grahas.get("Moon", {}).get("sign", natal_lagna_sign)
    natal_moon_idx = SIGNS_LIST.index(natal_moon_sign) if natal_moon_sign in SIGNS_LIST else 0

    # 2. Time Window Definition
    anchor_jd = swe.julday(
        start_year,
        start_month,
        start_day,
        start_hour + start_minute / 60.0 - transit_timezone
    )
    scan_start_jd = anchor_jd - days_back
    scan_end_jd = anchor_jd + days_forward
    total_days = int(math.ceil(scan_end_jd - scan_start_jd))

    active_dasha_lords_cfg = set(natal_chart.get("active_dasha_lords", []))
    antardashas_timeline = natal_chart.get("vimshottari_dasha", {}).get("antardashas", [])

    def _get_active_lords_at_jd(event_jd: float) -> Set[str]:
        if active_dasha_lords_cfg:
            return active_dasha_lords_cfg
        if antardashas_timeline:
            for ad in antardashas_timeline:
                if ad.get("start_jd", 0.0) <= event_jd < ad.get("end_jd", 0.0):
                    res = set()
                    m = ad.get("mahadasha_lord")
                    a = ad.get("antardasha_lord")
                    if m: res.add(m)
                    if a: res.add(a)
                    return res
        return set()

    raw_milestones: List[Dict[str, Any]] = []

    # 3. Step Through Ephemeris in 1-Day Increments
    # Pre-sample longitudes and speeds for all bodies at d and d+1
    # Day 0 to total_days
    sample_grid: Dict[str, List[Tuple[float, float]]] = {
        p: [] for p in set(STATION_PLANETS + INGRESS_PLANETS + EXACT_ASPECT_PLANETS)
    }

    for day_i in range(total_days + 1):
        cur_jd = scan_start_jd + day_i
        for p_name in sample_grid.keys():
            lon, sp = _get_planet_lon_and_speed(cur_jd, p_name)
            sample_grid[p_name].append((lon, sp))

    # =========================================================================
    # A. PLANETARY STATIONS (SR / SD)
    # =========================================================================
    for p_name in STATION_PLANETS:
        data_series = sample_grid[p_name]
        for day_i in range(total_days):
            sp1 = data_series[day_i][1]
            sp2 = data_series[day_i + 1][1]

            # Detect sign change of speed (direction reversal)
            if sp1 * sp2 <= 0.0 and sp1 != sp2:
                # Bisection to refine the exact moment speed == 0.0
                jd_a = scan_start_jd + day_i
                jd_b = scan_start_jd + day_i + 1.0
                st_type = "SR" if sp1 > 0 else "SD"

                for _ in range(16):  # 16 iterations gives ~1.3 seconds precision
                    jd_mid = (jd_a + jd_b) / 2.0
                    _, sp_mid = _get_planet_lon_and_speed(jd_mid, p_name)
                    if sp1 * sp_mid <= 0.0:
                        jd_b = jd_mid
                    else:
                        jd_a = jd_mid

                station_jd = (jd_a + jd_b) / 2.0
                station_lon, _ = _get_planet_lon_and_speed(station_jd, p_name)

                # Find if within 3°20' Navamsha orb of any natal target
                best_aspect_target: Optional[str] = None
                best_aspect_type: Optional[str] = None
                best_aspect_orb = 999.0

                candidate_glances = _get_candidate_aspects(p_name)
                for n_target, n_lon in natal_targets.items():
                    diff = (n_lon - station_lon) % 360.0
                    for asp_name, nominal_ang in candidate_glances:
                        signed_err = (diff - nominal_ang + 180.0) % 360.0 - 180.0
                        err = abs(signed_err)
                        if err <= aspect_orb_degrees and err < best_aspect_orb:
                            best_aspect_orb = err
                            best_aspect_target = n_target
                            best_aspect_type = asp_name

                time_dict = _revjul_to_dict(station_jd, transit_timezone)
                s_idx = int(station_lon // 30) % 12
                deg_in_sign = station_lon % 30.0
                deg = int(math.floor(deg_in_sign))
                minute = int(round((deg_in_sign - deg) * 60.0))
                if minute >= 60:
                    deg += 1
                    minute = 0
                if deg >= 30:
                    deg = 0
                    s_idx = (s_idx + 1) % 12

def calculate_transits(
    natal_chart: Dict[str, Any],
    transit_year: int,
    transit_month: int,
    transit_day: int,
    transit_hour: int = 12,
    transit_minute: int = 0,
    transit_second: int = 0,
    transit_latitude: float = 51.5074,
    transit_longitude: float = -0.1278,
    transit_timezone: float = 0.0,
    nakshatra_system: str = "ERNST_DHRUVA",
    debilitation_mode: str = "kala_degree",
    aspect_orb_degrees: float = 3.3333
) -> Dict[str, Any]:
    """
    Computes transiting planetary positions and evaluates their aspects,
    velocities, stationary states, and house positions relative to the native's natal chart.
    """
    # 1. Compute Transit Baseline snapshot using certified Stage 1 (zero redundant chart generation)
    transit_baseline = ChartBaseline(
        name="Transit",
        year=transit_year,
        month=transit_month,
        day=transit_day,
        hour=transit_hour,
        minute=transit_minute,
        second=transit_second,
        latitude=transit_latitude,
        longitude=transit_longitude,
        timezone_offset=transit_timezone,
        nakshatra_system=nakshatra_system
    )

    jd_ut = swe.julday(
        transit_year,
        transit_month,
        transit_day,
        transit_hour + transit_minute / 60.0 + transit_second / 3600.0 - transit_timezone
    )

    transit_d1 = copy.deepcopy(transit_baseline.vargas["D1"])
    t_naks = transit_baseline.nakshatras["grahas"]
    for p_name, g in transit_d1["grahas"].items():
        if p_name in t_naks:
            g["nakshatra"] = t_naks[p_name]["nakshatra"]
            g["pada"] = t_naks[p_name]["pada"]
    if "Lagna" in t_naks and "lagna" in transit_d1:
        transit_d1["lagna"]["nakshatra"] = t_naks["Lagna"]["nakshatra"]
        transit_d1["lagna"]["pada"] = t_naks["Lagna"]["pada"]

        "vargas": {
            "D1": transit_d1,
            "D9": transit_baseline.vargas.get("D9", {})

            continue

        p_sign = g.get("sign", "Aries")
        s_idx = SIGNS_LIST.index(p_sign) if p_sign in SIGNS_LIST else 0

                raw_speed = 0.0

                p_id = SWE_PLANET_MAP.get(p_name)
                if p_id is not None:

        elif is_retro:

            gati_sanskrit = "Vakri"

            motion_state = "Fast"
            gati_sanskrit = "Atichara"
        else:
            motion_state = "Direct"
            gati_sanskrit = "Rju"

        deg = int(math.floor(deg_val))
        minute = int(round((deg_val - deg) * 60.0))
        if minute >= 60:

            minute = 0

            s_idx = (s_idx + 1) % 12

            is_favorable_from_moon = h_from_moon in [1, 2, 3, 4, 5, 8, 9, 11, 12]
        elif p_name == "Mercury":
            is_favorable_from_moon = h_from_moon in [2, 4, 6, 8, 10, 11]
        elif p_name == "Moon":
            is_favorable_from_moon = h_from_moon in [1, 3, 6, 7, 10, 11]

        processed_transit_planets[p_name] = {
            "name": p_name,
            "sign": p_sign,
            "sign_idx": s_idx,
            "longitude": g.get("longitude", 0.0),
            "degree_0_to_30": g.get("degree_0_to_30", 0.0),
            "degree": deg,
            "minute": minute,
            "is_retrograde": is_retro,
            "daily_speed": round(daily_speed, 6),
            "speed_ratio": speed_ratio,
            "is_stationary": is_stationary,
            "station_type": station_type,
            "motion_state": motion_state,
            "gati_sanskrit": gati_sanskrit,
            "nakshatra": g.get("nakshatra", ""),
            "pada": g.get("pada", 1),
            "house_from_lagna": h_from_lagna,
            "house_from_moon": h_from_moon,
            "is_favorable_from_moon": is_favorable_from_moon
        }

    # 2B. Evaluate Classical Vedha (Obstruction) from Moon & Transit Vargottama (Phaladeepika Ch. 26)
    transit_d9_grahas = transit_chart.get("vargas", {}).get("D9", {}).get("grahas", {})
    for p_name, p_data in processed_transit_planets.items():
        h_moon = p_data["house_from_moon"]
        vedha_target = VEDHA_PAIRS.get(p_name, {}).get(h_moon)
        has_vedha = False
        obstructing = []
        if vedha_target is not None:
            for o_name, o_data in processed_transit_planets.items():
                if o_name == p_name:
                    continue
                if o_data["house_from_moon"] == vedha_target:
                    if VEDHA_EXCEPTIONS.get((p_name, o_name), True):
                        has_vedha = True
                        obstructing.append(o_name)
        p_data["has_vedha"] = has_vedha
        p_data["vedha_by"] = obstructing
        p_data["is_effective_benefic_from_moon"] = bool(p_data["is_favorable_from_moon"] and not has_vedha)

        d9_g = transit_d9_grahas.get(p_name, {})
        d9_sign = d9_g.get("sign")
        if not d9_sign:
            d9_sign_idx = int((p_data["longitude"] % 360.0) / (30.0 / 9.0)) % 12
            d9_sign = SIGNS_LIST[d9_sign_idx]
        p_data["is_vargottama"] = bool(d9_sign == p_data["sign"])

    active_dasha_lords = list(natal_chart.get("active_dasha_lords", []))
    if not active_dasha_lords and "vimshottari_dasha" in natal_chart:
        antardashas = natal_chart["vimshottari_dasha"].get("antardashas", [])
        for ad in antardashas:
            if ad.get("start_jd", 0.0) <= jd_ut < ad.get("end_jd", 0.0):
                m_lord = ad.get("mahadasha_lord")
                a_lord = ad.get("antardasha_lord")
                if m_lord and m_lord not in active_dasha_lords:
                    active_dasha_lords.append(m_lord)
                if a_lord and a_lord not in active_dasha_lords:
                    active_dasha_lords.append(a_lord)
                break

    # 3. Detect Active Transit Aspects onto Natal Planets
    active_aspects = get_transit_aspects(
        transit_grahas=transit_grahas,
        natal_grahas=natal_grahas,
        natal_lagna=natal_lagna,
        orb_degrees=aspect_orb_degrees,
        processed_transit_planets=processed_transit_planets,
        active_dasha_lords=active_dasha_lords
    )

    return {
        "transit_chart": transit_chart,
        "transit_planets": processed_transit_planets,
        "transit_lagna": transit_lagna,
        "natal_lagna_sign": natal_lagna_sign,
        "natal_moon_sign": natal_moon_sign,
        "active_aspects": active_aspects,
        "transit_time_info": {
            "year": transit_year,
            "month": transit_month,
            "day": transit_day,
            "hour": transit_hour,
            "minute": transit_minute,
            "second": transit_second,
            "formatted": f"{transit_day:02d}/{transit_month:02d}/{transit_year:04d} {transit_hour:02d}:{transit_minute:02d}:{transit_second:02d}"
        }
    }


def get_transit_aspects(
    transit_grahas: Dict[str, Any],
    natal_grahas: Dict[str, Any],
    natal_lagna: Dict[str, Any],
    orb_degrees: float = 3.3333,
    processed_transit_planets: Optional[Dict[str, Any]] = None,
    active_dasha_lords: Optional[List[str]] = None
) -> List[Dict[str, Any]]:
    """
    Finds all active Graha Drishti aspects and conjunctions cast by
    transiting planets onto natal planets and the natal Ascendant.
    """
    aspects = []
    natal_targets = dict(natal_grahas)
    if natal_lagna:
        natal_targets["Lagna"] = natal_lagna

    for t_name, t_info in transit_grahas.items():
        if t_name not in PLANET_ORDER:
            continue
        t_lon = t_info.get("longitude", 0.0)

        t_proc = (processed_transit_planets or {}).get(t_name, {})
        asp_is_stationary = bool(t_proc.get("is_stationary", False))
        asp_station_type = t_proc.get("station_type")
        asp_speed_ratio = float(t_proc.get("speed_ratio", 1.0))

        for n_name, n_info in natal_targets.items():
            n_lon = n_info.get("longitude", 0.0)
            diff = (n_lon - t_lon) % 360.0
            is_retro = bool(t_proc.get("is_retrograde", t_info.get("is_retrograde", False)))

            # 1. Conjunction (Yuti, 0°)
            orb_conj = diff if diff <= 180.0 else (360.0 - diff)
            if orb_conj <= orb_degrees:
                # Direct planet applies when moving towards n_lon (diff <= 180); retro applies when diff > 180
                is_applying = (diff <= 180.0) if not is_retro else (diff > 180.0)

                orb_closeness = max(0.0, 1.0 - (orb_conj / orb_degrees))
                virupa_factor = 60.0 / 60.0
                speed_factor = 2.0 if asp_is_stationary else (1.4 if asp_speed_ratio <= 0.50 else 1.0)
                is_dasha_synced = bool(active_dasha_lords and (t_name in active_dasha_lords or n_name in active_dasha_lords))
                base_weight = orb_closeness * virupa_factor * speed_factor
                if is_dasha_synced:
                    base_weight *= 1.35
                intensity_weight = round(base_weight, 3)

                is_benefic = t_name in ["Jupiter", "Venus", "Mercury"]
                if t_name == "Moon":
                    sun_item = transit_grahas.get("Sun", {})
                    s_lon = sun_item.get("longitude", 0.0)
                    moon_elong = (t_lon - s_lon) % 360.0
                    is_benefic = (0.0 <= moon_elong <= 180.0)

                aspects.append({
                    "aspecting": t_name,
                    "target": n_name,
                    "type": "Conjunction",
                    "code": "CONJ",
                    "angular_diff": round(diff, 2),
                    "orb": round(orb_conj, 2),
                    "virupas": 60.0,
                    "is_benefic": is_benefic,
                    "is_applying": is_applying,
                    "is_dasha_synchronized": is_dasha_synced,
                    "aspecting_is_stationary": asp_is_stationary,
                    "aspecting_station_type": asp_station_type,
                    "aspecting_speed_ratio": asp_speed_ratio,
                    "intensity_weight": intensity_weight,
                    "motion_status": "Applying" if is_applying else "Separating",
                    "description": f"Transiting {t_name} is conjunct Natal {n_name} (orb {round(orb_conj, 1)}°, {'Applying' if is_applying else 'Separating'})"
                })
                continue

            # 2. Classical Graha Drishti (Glances & Special Aspects)
            candidate_aspects = [("7th Opposition", 180.0)]
            if t_name == "Mars":
                candidate_aspects.extend([("4th Aspect", 90.0), ("8th Aspect", 210.0)])
            elif t_name == "Jupiter":
                candidate_aspects.extend([("5th Trine Aspect", 120.0), ("9th Trine Aspect", 240.0)])
            elif t_name == "Saturn":
                candidate_aspects.extend([("3rd Aspect", 60.0), ("10th Aspect", 270.0)])
            elif t_name in ["Rahu", "Ketu"]:
                candidate_aspects.extend([("5th Trine Aspect", 120.0), ("9th Trine Aspect", 240.0)])
            elif t_name in ["Sun", "Venus", "Mercury"]:
                candidate_aspects.extend([("5th Trine Glance", 120.0), ("9th Trine Glance", 240.0)])

            for glance_type, nominal_angle in candidate_aspects:
                signed_diff = (diff - nominal_angle + 180.0) % 360.0 - 180.0
                angle_error = abs(signed_diff)
                if angle_error <= orb_degrees:
                    virupas = get_graha_drishti(t_name, t_lon, n_lon) if t_name not in ["Rahu", "Ketu"] else 60.0
                    is_benefic = t_name in ["Jupiter", "Venus", "Mercury"]
                    if t_name == "Moon":
                        sun_item = transit_grahas.get("Sun", {})
                        s_lon = sun_item.get("longitude", 0.0)
                        moon_elong = (t_lon - s_lon) % 360.0
                        is_benefic = (0.0 <= moon_elong <= 180.0)
                    # Direct planet applies when signed_diff > 0 (before exact aspect); retro applies when signed_diff < 0
                    is_applying = (signed_diff > 0) if not is_retro else (signed_diff < 0)

                    orb_closeness = max(0.0, 1.0 - (angle_error / orb_degrees))
                    virupa_factor = min(1.0, max(0.1, virupas / 60.0))
                    speed_factor = 2.0 if asp_is_stationary else (1.4 if asp_speed_ratio <= 0.50 else 1.0)
                    is_dasha_synced = bool(active_dasha_lords and (t_name in active_dasha_lords or n_name in active_dasha_lords))
                    base_weight = orb_closeness * virupa_factor * speed_factor
                    if is_dasha_synced:
                        base_weight *= 1.35
                    intensity_weight = round(base_weight, 3)

                    aspects.append({
                        "aspecting": t_name,
                        "target": n_name,
                        "type": glance_type,
                        "code": "DRISHTI",
                        "angular_diff": round(diff, 2),
                        "orb": round(angle_error, 2),
                        "virupas": round(virupas, 1),
                        "is_benefic": is_benefic,
                        "is_applying": is_applying,
                        "is_dasha_synchronized": is_dasha_synced,
                        "aspecting_is_stationary": asp_is_stationary,
                        "aspecting_station_type": asp_station_type,
                        "aspecting_speed_ratio": asp_speed_ratio,
                        "intensity_weight": intensity_weight,
                        "motion_status": "Applying" if is_applying else "Separating",
                        "description": f"Transiting {t_name} casts {glance_type} on Natal {n_name} (orb {round(angle_error, 1)}°, {'Applying' if is_applying else 'Separating'})"
                    })

    # Sort aspects by intensity weight descending so stationary / exact hits come first
    aspects.sort(key=lambda a: a.get("intensity_weight", 0.0), reverse=True)
    return aspects

/**
 * Astra Transit Bi-Wheel Widget (Gochara)
 * 
 * Provides an interactive 2-ring Transit Bi-Wheel (Kala style):
 * - Real-time and date-stepper controls (minutely, 10-min, hourly, daily, weekly, monthly, yearly)
 * - Continuous Play / Pause animation loop
 * - Dynamic aspect chords connecting transiting planets to natal targets (Phaladeepika 3°20' orb)
 * - Triple perspective: Lagna, Chandra Lagna (Moon), and Surya Lagna (Sun)
 * - Bulletproof date parsing & live date readout
 */

(function() {
    // Registry of active widget instances mapped by container element
    const activeInstances = new Map();

    function getActiveNativeId() {
        if (window.currentLoadedNative && window.currentLoadedNative.id) {
            return window.currentLoadedNative.id;
        }
        if (window.astraStore && window.astraStore.state && window.astraStore.state.currentNative && window.astraStore.state.currentNative.id) {
            return window.astraStore.state.currentNative.id;
        }
        if (window.currentChartData && window.currentChartData.subject_info && window.currentChartData.subject_info.id) {
            return window.currentChartData.subject_info.id;
        }
        const select = document.getElementById('nativeSelect');
        if (select && select.value && select.value !== '__open_chart_dialog__') {
            return select.value;
        }
        if (select && select.options && select.options.length > 1) {
            for (let i = 1; i < select.options.length; i++) {
                const val = select.options[i].value;
                if (val && val !== '__open_chart_dialog__') {
                    return val;
                }
            }
        }
        return '';
    }

    function formatLocalDate(d) {
        if (!d || isNaN(d.getTime())) d = new Date();
        const y = d.getFullYear();
        const m = String(d.getMonth() + 1).padStart(2, '0');
        const day = String(d.getDate()).padStart(2, '0');
        return `${y}-${m}-${day}`;
    }

    function formatDisplayDate(d) {
        if (!d || isNaN(d.getTime())) d = new Date();
        const y = d.getFullYear();
        const m = String(d.getMonth() + 1).padStart(2, '0');
        const day = String(d.getDate()).padStart(2, '0');
        return `${day}/${m}/${y}`;
    }

    function formatLocalTime(d) {
        if (!d || isNaN(d.getTime())) d = new Date();
        const h = String(d.getHours()).padStart(2, '0');
        const m = String(d.getMinutes()).padStart(2, '0');
        const s = String(d.getSeconds()).padStart(2, '0');
        return `${h}:${m}:${s}`;
    }

    function formatFullDateTime(d) {
        if (!d || isNaN(d.getTime())) d = new Date();
        return `${formatDisplayDate(d)} ${formatLocalTime(d)}`;
    }

    function parseDateString(str) {
        if (!str) return new Date();
        const clean = str.trim();
        // 1. Matches YYYY-MM-DD or YYYY.MM.DD or YYYY/MM/DD
        let match = clean.match(/^(\d{4})[-./\s]+(\d{1,2})[-./\s]+(\d{1,2})\.?$/);
        if (match) {
            const y = parseInt(match[1], 10);
            const m = parseInt(match[2], 10) - 1;
            const d = parseInt(match[3], 10);
            const dt = new Date(y, m, d);
            return isNaN(dt.getTime()) ? new Date() : dt;
        }
        // 2. Matches DD/MM/YYYY or DD-MM-YYYY or DD.MM.YYYY
        match = clean.match(/^(\d{1,2})[-./\s]+(\d{1,2})[-./\s]+(\d{4})$/);
        if (match) {
            const d = parseInt(match[1], 10);
            const m = parseInt(match[2], 10) - 1;
            const y = parseInt(match[3], 10);
            const dt = new Date(y, m, d);
            return isNaN(dt.getTime()) ? new Date() : dt;
        }
        const parsed = new Date(clean);
        return isNaN(parsed.getTime()) ? new Date() : parsed;
    }

    function pulseLiveBadge(cell) {

    function stepTime(state, direction, multiplier = 1, onComplete = null) {
        if (!state.currentDate || isNaN(state.currentDate.getTime())) {
            state.currentDate = new Date();
        }
        const d = new Date(state.currentDate.getTime());
        const stepVal = direction * multiplier;

        switch (state.interval) {
            case 'realtime':
                state.currentDate = new Date();
                break;
            case '1m':
                d.setMinutes(d.getMinutes() + stepVal * 1);
                state.currentDate = d;
                break;
            case '10m':
                d.setMinutes(d.getMinutes() + stepVal * 10);
                state.currentDate = d;
                break;
            case '1h':
                d.setHours(d.getHours() + stepVal * 1);
                state.currentDate = d;
                break;
            case '1d':
                d.setDate(d.getDate() + stepVal * 1);
                state.currentDate = d;
                break;
            case '1w':
                d.setDate(d.getDate() + stepVal * 7);
                state.currentDate = d;
                break;
            case '30d':
                d.setDate(d.getDate() + stepVal * 30);
                state.currentDate = d;
                break;
            case '365d':
                d.setFullYear(d.getFullYear() + stepVal * 1);
                state.currentDate = d;
                break;
            default:
                d.setDate(d.getDate() + stepVal * 1);
                state.currentDate = d;
        }

        pulseLiveBadge(state.cell);
        syncInputsFromState(state);
        fetchAndRender(state, onComplete);
    }

    function syncInputsFromState(state) {
        const cell = state.cell;
        if (!cell) return;
        const dateInput = cell.querySelector('.transit-date-input');
        const timeInput = cell.querySelector('.transit-time-input');
        const displayLabel = cell.querySelector('.transit-date-display-text');
        const intervalSelect = cell.querySelector('.transit-interval-select');
        const orbSelect = cell.querySelector('.transit-orb-select');

        if (dateInput) dateInput.value = formatLocalDate(state.currentDate);
        if (timeInput) timeInput.value = formatLocalTime(state.currentDate);
        if (displayLabel) displayLabel.textContent = formatFullDateTime(state.currentDate);
        if (intervalSelect && state.interval) intervalSelect.value = state.interval;
        if (orbSelect && state.orb) orbSelect.value = String(state.orb);
    }

    function scheduleNextPlay(state) {
        if (!state.isPlaying) return;
        let speedMs = 300;
        if (state.interval === 'realtime') speedMs = 1000;
        else if (['1w', '30d'].includes(state.interval)) speedMs = 350;
        else if (state.interval === '365d') speedMs = 450;

        state.playTimer = setTimeout(() => {
            if (!state.isPlaying) return;
            stepTime(state, 1, 1, () => {
                if (state.isPlaying) {
                    scheduleNextPlay(state);
                }
            });
        }, speedMs);
    }

    function togglePlay(state) {
        const cell = state.cell;
        const playBtn = cell.querySelector('.btn-transit-play-pause');
        const dot = cell.querySelector('.transit-status-dot');

        if (state.isPlaying) {
            // Stop
            if (state.playTimer) clearTimeout(state.playTimer);
            state.playTimer = null;
            state.isPlaying = false;
            if (playBtn) {
                playBtn.innerHTML = '&#9654; Play';
                playBtn.style.background = '#d35400';
            }
            if (dot) dot.style.color = '#27ae60';
        } else {
            // Start
            state.isPlaying = true;
            if (playBtn) {
                playBtn.innerHTML = '&#10074;&#10074; Pause';
                playBtn.style.background = '#c0392b';
            }
            if (dot) dot.style.color = '#e74c3c';
            scheduleNextPlay(state);
        }
    }

    function jumpToMilestone(state, dateStr, timeStr) {
        if (!dateStr) return;
        const parsed = parseDateString(dateStr);
        if (timeStr) {
            const parts = timeStr.split(':');
            parsed.setHours(
                parseInt(parts[0], 10) || 0,
                parseInt(parts[1], 10) || 0,
                parseInt(parts[2], 10) || 0
            );
        }
        state.currentDate = parsed;
        pulseLiveBadge(state.cell);
        syncInputsFromState(state);
        fetchAndRender(state);
    }

    function stepMilestone(state, direction) {
        if (!state.milestones || state.milestones.length === 0) return;
        const curTime = state.currentDate.getTime();
        const thresholdMs = 45 * 1000;

        // Respect active radar filter when stepping
        const filter = state.radarFilter || 'all';
        let list = state.milestones;
        if (filter === 'macro') {
            list = state.milestones.filter(m => m.is_macro_planet !== false);
        } else if (filter === 'stations') {
            list = state.milestones.filter(m => m.category === 'NATAL_STATION' || m.category === 'SKY_STATION');
        } else if (filter === 'natal_hits') {
            list = state.milestones.filter(m => m.category === 'NATAL_STATION' || m.category === 'EXACT_ASPECT');
        } else if (filter === 'ingresses') {
            list = state.milestones.filter(m => m.category === 'SIGN_INGRESS');
        }
        if (list.length === 0) list = state.milestones;

        if (direction > 0) {
            let nextM = list.find(m => {
                const mDt = parseDateString(m.jump_date);
                if (m.jump_time) {
                    const p = m.jump_time.split(':');
                    mDt.setHours(parseInt(p[0], 10) || 0, parseInt(p[1], 10) || 0, parseInt(p[2], 10) || 0);
                }
                return mDt.getTime() > curTime + thresholdMs;
            });
            if (!nextM) nextM = list[list.length - 1];
            if (nextM) jumpToMilestone(state, nextM.jump_date, nextM.jump_time);
        } else {
            let prevM = null;
            for (let i = list.length - 1; i >= 0; i--) {
                const m = list[i];
                const mDt = parseDateString(m.jump_date);
                if (m.jump_time) {
                    const p = m.jump_time.split(':');
                    mDt.setHours(parseInt(p[0], 10) || 0, parseInt(p[1], 10) || 0, parseInt(p[2], 10) || 0);
                }
                if (mDt.getTime() < curTime - thresholdMs) {
                    prevM = m;
                    break;
                }
            }
            if (!prevM) prevM = list[0];
            if (prevM) jumpToMilestone(state, prevM.jump_date, prevM.jump_time);
        }
    }

    function renderMilestones(state) {
        const cell = state.cell;
        if (!cell) return;
        const listContainer = cell.querySelector('.transit-radar-list');
        const countBadge = cell.querySelector('.transit-radar-count');
        if (!listContainer) return;

        const allMilestones = state.milestones || [];
        const filter = state.radarFilter || 'all';
        let filtered = allMilestones;
        if (filter === 'macro') {
            filtered = allMilestones.filter(m => m.is_macro_planet !== false);
        } else if (filter === 'stations') {
            filtered = allMilestones.filter(m => m.category === 'NATAL_STATION' || m.category === 'SKY_STATION');
        } else if (filter === 'natal_hits') {
            filtered = allMilestones.filter(m => m.category === 'NATAL_STATION' || m.category === 'EXACT_ASPECT');
        } else if (filter === 'ingresses') {
            filtered = allMilestones.filter(m => m.category === 'SIGN_INGRESS');
        }

        if (countBadge) countBadge.textContent = filtered.length;

        listContainer.innerHTML = '';
        if (filtered.length === 0) {
            listContainer.innerHTML = '<div style="font-size:12px; color:#8c7b64; text-align:center; padding:15px;">No milestones found in this filter category.</div>';
            return;
        }

        const curTime = state.currentDate.getTime();
        let closestDist = Infinity;
        let closestCard = null;

        filtered.forEach(m => {
            const card = document.createElement('div');
            card.className = 'transit-milestone-card';
            card.dataset.category = m.category;
            card.dataset.jumpDate = m.jump_date;
            card.dataset.jumpTime = m.jump_time;

            const mDt = parseDateString(m.jump_date);
            if (m.jump_time) {
                const p = m.jump_time.split(':');
                mDt.setHours(parseInt(p[0], 10) || 0, parseInt(p[1], 10) || 0, parseInt(p[2], 10) || 0);
            }
            const dist = Math.abs(mDt.getTime() - curTime);

            let leftAccent = '#94a3b8';
            let labelClass = 'radar-label-sky-station';
            let labelText = '';

            if (m.category === 'NATAL_STATION') {
                leftAccent = '#b91c1c';
                labelClass = 'radar-label-natal-station';
                labelText = '★ STATION ON NATAL';
            } else if (m.category === 'EXACT_ASPECT') {
                leftAccent = '#b45309';
                labelClass = 'radar-label-exact-aspect';
                const passStr = (m.total_passes && m.total_passes > 1) ? ` (Pass ${m.pass_number}/${m.total_passes})` : '';
                labelText = `◎ EXACT HIT${passStr}`;
            } else if (m.category === 'SIGN_INGRESS') {
                leftAccent = '#0f766e';
                labelClass = 'radar-label-ingress';
                labelText = '→ INGRESS';
            } else {
                leftAccent = '#64748b';
                labelClass = 'radar-label-sky-station';
                const stStr = m.station_type ? ` · ${m.station_type}` : '';
                labelText = `⟲ STATION${stStr}`;
            }

            const timeLabel = `${m.formatted_date} · ${String(m.hour).padStart(2, '0')}:${String(m.minute).padStart(2, '0')}`;
            const dashaTag = m.is_dasha_synchronized
                ? `<span style="font-size:12px; font-weight:700; color:#b45309; margin-left:6px;" title="Active Dasha Lord Event (Vimshottari Synchronized)">[DASHA LORD]</span>`
                : '';

            card.style.borderLeftColor = leftAccent;

            card.innerHTML = `
                <div style="display:flex; justify-content:space-between; align-items:center;">
                    <span style="font-size:12px; font-weight:600; color:#5c4433; font-variant-numeric:tabular-nums; letter-spacing:0.3px;">${timeLabel}${dashaTag}</span>
                    <span class="${labelClass}" style="font-size:12px; font-weight:700; letter-spacing:0.5px; text-transform:uppercase;">${labelText}</span>
                </div>
                <div style="font-size:12.5px; font-weight:500; color:#2c221b; line-height:1.35; font-family:var(--font-german-din, 'DIN Alternate', -apple-system, sans-serif);">
                    ${m.description}
                </div>
            `;

            if (dist < closestDist) {
                closestDist = dist;
                closestCard = card;
            }

            card.addEventListener('click', () => {
                jumpToMilestone(state, m.jump_date, m.jump_time);
            });

            card.addEventListener('mouseenter', () => {
                if (m.planet && m.natal_target) {
                    highlightTransitAspect(cell, m.planet, m.natal_target);
                }
            });

            card.addEventListener('mouseleave', () => {
                resetTransitAspectHighlights(cell);
            });

            listContainer.appendChild(card);
        });

        // Highlight closest card within 24 hours
        if (closestCard && closestDist < (24 * 3600 * 1000)) {
            closestCard.classList.add('active-jumped');
            closestCard.scrollIntoView({ block: 'nearest', behavior: 'smooth' });
        }
    }

    function fetchAndRender(state, onComplete = null) {
        const cell = state.cell;
        if (!cell) {
            if (typeof onComplete === 'function') onComplete();
            return;
        }

        const natId = getActiveNativeId();
        if (!natId) {
            const svgContainer = cell.querySelector('.transit-svg-container');
            if (svgContainer) {
                svgContainer.innerHTML = '<div style="font-size:13px; color:#8c7b64; padding:20px; text-align:center;">Please load or select a person from the top toolbar to view transits.</div>';
            }
            if (typeof onComplete === 'function') onComplete();
            return;
        }

        // Cancel previous pending fetch only if NOT in play loop
        if (!state.isPlaying && state.abortController) {
            state.abortController.abort();
            state.abortController = null;
        }
        if (!state.abortController) {
            state.abortController = new AbortController();
        }

        const dateStr = formatLocalDate(state.currentDate);
        const timeStr = formatLocalTime(state.currentDate);
        const nakSys = window.currentNakshatraSystem || 'ERNST_DHRUVA';
        const debMode = window.currentDebilitationMode || 'kala_degree';
        const notation = window.currentNotation || 'symbol';
        const showNak = (typeof window.currentShowNakshatras !== 'undefined') ? window.currentShowNakshatras : false;

        const orbVal = state.orb || 3.3333;
        const url = `/api/chart/${natId}/transit?transit_date=${dateStr}&transit_time=${timeStr}&orb=${orbVal}&nakshatra_system=${nakSys}&debilitation_mode=${debMode}&mode=${notation}&root=${state.root}&show_nakshatras=${showNak}`;

        fetch(url, { signal: state.abortController.signal })
            .then(res => {
                if (!res.ok) throw new Error(`HTTP ${res.status}`);
                return res.json();
            })
            .then(data => {
                if (!data || !data.svg) return;

                const svgContainer = cell.querySelector('.transit-svg-container');
                if (svgContainer) {
                    svgContainer.innerHTML = data.svg;
                    attachSvgInteractivity(cell);
                }

                // Update aspects table & badge
                const countBadge = cell.querySelector('.transit-aspect-count');
                const aspects = data.active_aspects || [];
                if (countBadge) countBadge.textContent = aspects.length;

                const tbody = cell.querySelector('.transit-aspects-tbody');
                if (tbody) {
                    tbody.innerHTML = '';
                    if (aspects.length === 0) {
                        tbody.innerHTML = `<tr><td colspan="6" style="padding:6px; color:#8c7b64; text-align:center; font-size:12px;">No active transit triggers within ${orbVal === 3.3333 ? "3°20' Navāmśa" : orbVal + "°"} orb.</td></tr>`;
                    } else {
                        aspects.forEach(asp => {
                            const tr = document.createElement('tr');
                            tr.className = 'transit-aspect-row';
                            tr.style.borderBottom = '1px solid #edece6';
                            tr.style.cursor = 'pointer';
                            tr.dataset.from = asp.aspecting;
                            tr.dataset.to = asp.target;

                            const col = asp.is_benefic ? '#27ae60' : (asp.code === 'CONJ' ? '#8e44ad' : '#c0392b');
                            const motionText = asp.motion_status || (asp.is_applying ? 'Applying' : 'Separating');
                            const motionColor = asp.is_applying ? '#2e7d32' : '#795548';
                            const motionArrow = asp.is_applying ? '→' : '←';
                            const dashaBadge = asp.is_dasha_synchronized
                                ? `<span style="font-size:12px; font-weight:700; color:#b45309; margin-left:4px;" title="Active Dasha Lord Transit (1.35x Synchronization Multiplier)">[DASHA LORD]</span>`
                                : '';

                            tr.innerHTML = `
                                <td style="padding:3px 6px; font-weight:bold; color:${col}; font-size:12px;">${asp.aspecting}${dashaBadge}</td>
                                <td style="padding:3px 6px; font-size:12px;">${asp.type}</td>
                                <td style="padding:3px 6px; font-weight:600; font-size:12px;">Natal ${asp.target}</td>
                                <td style="padding:3px 6px; font-variant-numeric:tabular-nums; font-size:12px;">${asp.orb}°</td>
                                <td style="padding:3px 6px; font-variant-numeric:tabular-nums; font-size:12px;">${asp.virupas} V</td>
                                <td style="padding:3px 6px; font-size:12px; font-weight:600; color:${motionColor}; font-variant-numeric:tabular-nums;">${motionArrow} ${motionText}</td>
                            `;

                            tr.addEventListener('mouseenter', () => {
                                tr.style.background = '#f5eedb';
                                highlightTransitAspect(cell, asp.aspecting, asp.target);
                            });
                            tr.addEventListener('mouseleave', () => {
                                tr.style.background = 'transparent';
                                resetTransitAspectHighlights(cell);
                            });

                            tbody.appendChild(tr);
                        });
                    }
                }

                const tsBadge = cell.querySelector('.transit-timestamp-badge');
                if (tsBadge && data.transit_time_info) {
                    tsBadge.textContent = data.transit_time_info.formatted;
                }

                // Update the live formatted date display badge
                const displayLabel = cell.querySelector('.transit-date-display-text');
                if (displayLabel) {
                    displayLabel.textContent = formatFullDateTime(state.currentDate);
                }

                // Update Milestones & Upcoming Stations in the Gochara Radar Panel
                state.milestones = data.milestones || [];
                state.upcomingStations = data.upcoming_stations || [];
                renderMilestones(state);
            })
            .catch(err => {
                if (err.name === 'AbortError') return; // Expected cancellation on fast step
                console.error("Error fetching transit chart:", err);
            })
            .finally(() => {
                if (typeof onComplete === 'function') {
                    onComplete();
                }
            });
    }

    function highlightTransitAspect(cell, fromPlanet, toPlanet) {
        const svg = cell.querySelector('.transit-biwheel-svg');
        if (!svg) return;

        const lines = svg.querySelectorAll('.transit-aspect-line');
        lines.forEach(l => {
            const match = (l.getAttribute('data-from') === fromPlanet && l.getAttribute('data-to') === toPlanet);
            l.style.opacity = match ? '1.0' : '0.12';
            l.style.strokeWidth = match ? '2.4px' : '0.8px';
        });

        // Highlight matching dots
        svg.querySelectorAll('.transit-planet-dot').forEach(d => {
            d.style.strokeWidth = (d.getAttribute('data-planet') === fromPlanet) ? '2.0px' : '0.8px';
            d.style.r = (d.getAttribute('data-planet') === fromPlanet) ? '4.0' : '2.8';
        });
        svg.querySelectorAll('.natal-planet-dot').forEach(d => {
            d.style.strokeWidth = (d.getAttribute('data-planet') === toPlanet) ? '2.0px' : '0.8px';
            d.style.r = (d.getAttribute('data-planet') === toPlanet) ? '4.0' : '2.8';
        });
    }

    function attachSvgInteractivity(cell) {
        const svg = cell.querySelector('.transit-biwheel-svg');
        if (!svg) return;
        const state = activeInstances.get(cell);
        if (!state) return;

        const outerPlanets = svg.querySelectorAll('.outer-planet, .transit-planet');
        const innerPlanets = svg.querySelectorAll('.inner-planet, .natal-planet');
        const aspectLines = svg.querySelectorAll('.transit-aspect-line');

        // 1. Hover on Outer Transiting Planet -> Highlight outbound aspects
        outerPlanets.forEach(p => {
            const pName = p.getAttribute('data-planet');
            if (!pName) return;

            p.addEventListener('mouseenter', () => {
                let hitCount = 0;
                aspectLines.forEach(line => {
                    if (line.getAttribute('data-from') === pName) {
                        line.style.opacity = '1.0';
                        line.style.strokeWidth = '2.2px';
                        hitCount++;
                    } else {
                        line.style.opacity = '0.12';
                        line.style.strokeWidth = '0.8px';
                    }
                });
            });

            p.addEventListener('mouseleave', () => resetTransitAspectHighlights(cell));
        });

        // 2. Hover on Inner Natal Planet -> Highlight inbound aspects to this target
        innerPlanets.forEach(p => {
            const pName = p.getAttribute('data-planet') || p.getAttribute('data-id');
            if (!pName) return;

            p.addEventListener('mouseenter', () => {
                aspectLines.forEach(line => {
                    if (line.getAttribute('data-to') === pName) {
                        line.style.opacity = '1.0';
                        line.style.strokeWidth = '2.2px';
                    } else {
                        line.style.opacity = '0.12';
                        line.style.strokeWidth = '0.8px';
                    }
                });
            });

            p.addEventListener('mouseleave', () => resetTransitAspectHighlights(cell));
        });

        // 3. Hover directly on Aspect Line
        aspectLines.forEach(line => {
            line.addEventListener('mouseenter', () => {
                aspectLines.forEach(l => {
                    if (l === line) {
                        l.style.opacity = '1.0';
                        l.style.strokeWidth = '2.5px';
                    } else {
                        l.style.opacity = '0.15';
                        l.style.strokeWidth = '0.8px';
                    }
                });
            });
            line.addEventListener('mouseleave', () => resetTransitAspectHighlights(cell));
        });

        // 4. Station Pins on Outer Rim (Click to jump, Hover for feedback)
        const stationPins = svg.querySelectorAll('.station-pin, .interactive-station-pin');
        stationPins.forEach(pin => {
            pin.addEventListener('click', (e) => {
                e.stopPropagation();
                const jDate = pin.getAttribute('data-jump-date');
                const jTime = pin.getAttribute('data-jump-time');
                if (jDate) {
                    jumpToMilestone(state, jDate, jTime || '12:00:00');
                }
            });
        });
    }

    function initTransitWidget(cell) {
        let state = activeInstances.get(cell);
        if (state) {
            // Clean up any existing playback timers on re-initialization
            if (state.playTimer) clearTimeout(state.playTimer);
            state.playTimer = null;
            state.isPlaying = false;
            state.cell = cell;
        } else {
            state = createInstanceState(cell);
            activeInstances.set(cell, state);
        }

        syncInputsFromState(state);

        // Bind Stepper Controls
        const btnStepBack = cell.querySelector('.btn-transit-step-back');
        const btnStepFwd = cell.querySelector('.btn-transit-step-fwd');
        const btnFastBack = cell.querySelector('.btn-transit-step-fast-back');
        const btnFastFwd = cell.querySelector('.btn-transit-step-fast-fwd');
        const btnNow = cell.querySelector('.btn-transit-now');
        const btnPlay = cell.querySelector('.btn-transit-play-pause');
        const intervalSelect = cell.querySelector('.transit-interval-select');
        const dateInput = cell.querySelector('.transit-date-input');
        const timeInput = cell.querySelector('.transit-time-input');
        const btnRootLagna = cell.querySelector('.btn-transit-root-lagna');
        const btnRootMoon = cell.querySelector('.btn-transit-root-moon');
        const btnRootSun = cell.querySelector('.btn-transit-root-sun');
        const btnToggleTable = cell.querySelector('.btn-transit-toggle-table');
        const drawer = cell.querySelector('.transit-aspects-drawer');

        const btnSyncNatal = cell.querySelector('.btn-transit-sync-natal');
        const orbSelect = cell.querySelector('.transit-orb-select');

        if (btnStepBack) btnStepBack.onclick = () => stepTime(state, -1, 1);
        if (btnStepFwd) btnStepFwd.onclick = () => stepTime(state, 1, 1);
        if (btnFastBack) btnFastBack.onclick = () => stepTime(state, -1, 5);
        if (btnFastFwd) btnFastFwd.onclick = () => stepTime(state, 1, 5);

        if (btnNow) {
            btnNow.onclick = () => {
                state.currentDate = new Date();
                pulseLiveBadge(cell);
                syncInputsFromState(state);
                fetchAndRender(state);
            };
        }

        if (btnSyncNatal) {
            btnSyncNatal.onclick = () => {
                const subj = (window.currentChartData && window.currentChartData.subject_info) || window.currentLoadedNative;
                if (subj && subj.date) {
                    const parsedDate = parseDateString(subj.date);
                    if (subj.time) {
                        const parts = subj.time.split(':');
                        parsedDate.setHours(parseInt(parts[0], 10) || 12, parseInt(parts[1], 10) || 0, parseInt(parts[2], 10) || 0);
                    }
                    state.currentDate = parsedDate;
                    pulseLiveBadge(cell);
                    syncInputsFromState(state);
                    fetchAndRender(state);
                }
            };
        }

        if (btnPlay) {
            btnPlay.onclick = () => togglePlay(state);
        }

        if (intervalSelect) {
            intervalSelect.value = state.interval;
            intervalSelect.onchange = () => {
                state.interval = intervalSelect.value;
                if (state.isPlaying) {
                    togglePlay(state); // Stop
                    togglePlay(state); // Restart with new interval speed
                }
            };
        }

        if (orbSelect) {
            orbSelect.value = String(state.orb || 3.3333);
            orbSelect.onchange = () => {
                state.orb = parseFloat(orbSelect.value) || 3.3333;
                fetchAndRender(state);
            };
        }

        const handleDateChange = () => {
            if (dateInput && dateInput.value) {
                const parts = dateInput.value.split('-');
                if (parts.length === 3) {
                    const y = parseInt(parts[0], 10);
                    const m = parseInt(parts[1], 10) - 1;
                    const d = parseInt(parts[2], 10);
                    if (!isNaN(y) && !isNaN(m) && !isNaN(d) && y > 100 && d > 0 && d <= 31) {
                        state.currentDate.setFullYear(y, m, d);
                        pulseLiveBadge(cell);
                        syncInputsFromState(state);
                        fetchAndRender(state);
                    }
                }
            }
        };

        if (dateInput) {
            dateInput.onchange = handleDateChange;
            dateInput.addEventListener('keydown', (e) => {
                if (e.key === 'Enter') handleDateChange();
            });
        }

        const handleTimeChange = () => {
            if (timeInput && timeInput.value) {
                const parts = timeInput.value.split(':');
                if (parts.length >= 2) {
                    const h = parseInt(parts[0], 10);
                    const m = parseInt(parts[1], 10);
                    const s = parts.length > 2 ? parseInt(parts[2], 10) : 0;
                    if (!isNaN(h) && !isNaN(m)) {
                        state.currentDate.setHours(h, m, isNaN(s) ? 0 : s);
                        pulseLiveBadge(cell);
                        syncInputsFromState(state);
                        fetchAndRender(state);
                    }
                }
            }
        };

        if (timeInput) {
            timeInput.onchange = handleTimeChange;
            timeInput.addEventListener('keydown', (e) => {
                if (e.key === 'Enter') handleTimeChange();
            });
        }

        if (btnRootLagna) btnRootLagna.onclick = () => setRootPerspective(state, 'Lagna');
        if (btnRootMoon) btnRootMoon.onclick = () => setRootPerspective(state, 'Moon');
        if (btnRootSun) btnRootSun.onclick = () => setRootPerspective(state, 'Sun');

        if (btnToggleTable && drawer) {
            btnToggleTable.onclick = () => {
                state.showTable = !state.showTable;
                drawer.style.display = state.showTable ? 'block' : 'none';
            };
        }

        // Bind Milestone Step and Radar Controls
        const btnMilestonePrev = cell.querySelector('.btn-transit-step-milestone-prev');
        const btnMilestoneNext = cell.querySelector('.btn-transit-step-milestone-next');
        const btnToggleRadar = cell.querySelector('.btn-transit-toggle-radar');
        const radarPanel = cell.querySelector('.transit-radar-panel');

        if (btnMilestonePrev) btnMilestonePrev.onclick = () => stepMilestone(state, -1);
        if (btnMilestoneNext) btnMilestoneNext.onclick = () => stepMilestone(state, 1);

        if (btnToggleRadar && radarPanel) {
            btnToggleRadar.onclick = () => {
                state.showRadar = !state.showRadar;
                radarPanel.style.display = state.showRadar ? 'flex' : 'none';
                if (state.showRadar) {
                    btnToggleRadar.classList.add('active');
                    btnToggleRadar.style.background = '#fff8f0';
                    btnToggleRadar.style.borderColor = '#c2410c';
                    btnToggleRadar.style.color = '#c2410c';
                } else {
                    btnToggleRadar.classList.remove('active');
                    btnToggleRadar.style.background = '#fffdfa';
                    btnToggleRadar.style.borderColor = '#d5c8b2';
                    btnToggleRadar.style.color = '#4a3325';
                }
            };
        }

        const filterTabs = cell.querySelectorAll('.radar-filter-tab, .radar-filter-pill');
        filterTabs.forEach(tab => {
            tab.onclick = () => {
                filterTabs.forEach(t => t.classList.remove('active'));
                tab.classList.add('active');
                state.radarFilter = tab.getAttribute('data-filter') || 'all';
                renderMilestones(state);
            };
        });

        fetchAndRender(state);
    }

    // Register widget in WidgetRegistry
    if (typeof window !== 'undefined' && window.widgetRegistry) {
        window.widgetRegistry.register('transit-chart', {
            id: 'transit-chart',
            title: 'Transit Bi-Wheel',
            icon: '🪐',
            category: 'Charts',
            templateId: 'tmpl-transit-chart',
            render: function(container, chartData, options) {
                const tmpl = document.getElementById('tmpl-transit-chart');
                if (tmpl) {
                    container.innerHTML = tmpl.innerHTML;
                    initTransitWidget(container);
                }
            },
            onUpdate: function(cell, chartData) {
                initTransitWidget(cell);
            }
        });
    }

    // Open Transit Bi-Wheel in a Floating Modal Window
    function openFloatingTransit() {
        const modal = document.getElementById('widgetMaximizeModal');
        const card = document.getElementById('widgetMaximizeCard');
        const titleEl = document.getElementById('widgetMaximizeModalTitle');
        const container = document.getElementById('widgetMaximizeContainer');
        if (!modal || !titleEl || !container) return;

        if (typeof resetFloatingWindowPosition === 'function') resetFloatingWindowPosition();
        if (card) {
            const w = Math.min(1050, window.innerWidth - 40);
            const h = Math.min(860, window.innerHeight - 60);
            card.style.width = w + 'px';
            card.style.height = h + 'px';
            card.style.left = Math.max(20, Math.round((window.innerWidth - w) / 2)) + 'px';
            card.style.top = Math.max(30, Math.round((window.innerHeight - h) / 2)) + 'px';
        }

        titleEl.textContent = '🪐 Animated Transit Bi-Wheel (Gochara)';
        modal.style.display = 'block';

        const tmpl = document.getElementById('tmpl-transit-chart');
        if (tmpl) {
            container.innerHTML = tmpl.innerHTML;
            initTransitWidget(container);
        }

        // Highlight nav pill if present
        const navPills = document.querySelectorAll('.floating-nav-pill');
        navPills.forEach(p => p.classList.remove('active'));
        const transitPill = document.getElementById('nav-btn-transit');
        if (transitPill) transitPill.classList.add('active');
    }

    // Switch from transit widget back to normal chart widget with requested style
    function switchTransitToChart(btn, style) {
        const cell = btn.closest('.grid-cell');
        if (!cell) return;
        const state = activeInstances.get(cell);
        if (state && state.playTimer) {
            clearTimeout(state.playTimer);
            state.playTimer = null;
            state.isPlaying = false;
        }
        if (typeof window.assignWidget === 'function') {
            window.assignWidget('chart', cell, { chart_style: style });
        }
    }

    function maximizeTransitFromWidget(btn) {
        if (typeof openFloatingTransit === 'function') {
            openFloatingTransit();
        }
    }

    // Export globally for testing / manual invocation
    if (typeof window !== 'undefined') {
        window.initTransitWidget = initTransitWidget;
        window.openFloatingTransit = openFloatingTransit;
        window.switchTransitToChart = switchTransitToChart;
        window.maximizeTransitFromWidget = maximizeTransitFromWidget;
    }
})();
