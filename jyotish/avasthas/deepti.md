# AI Documentation: deepti.py (Deeptadi Avasthas)

## Logic constraints for AI
* **Base Engine:** Uses **Compound Friendship (Panchadha)**. 
* **Priority:** Physical/Astronomical states take precedence over sign dignity.
* **Order of Evaluation (Important):**
  1. `Retrograde` -> Sakta (Powerful)
  2. `Combust` -> Kopa/Mushita (Angry)
  3. `Conjunct Malefic` -> Vikala (Agitated)
  4. If no physical afflictions, map the 5-fold compound dignity directly to the remaining states (Exalted -> Deepta, Great Friend's Sign -> Mudita, Enemy's Sign -> Dukhita, etc.).
