# AI Documentation: jagrat.py (Jagradadi Avasthas)

## Logic constraints for AI
* **Base Engine:** Uses **Compound Friendship (Panchadha)** for the sign placement (Dignity).
* **States:**
  - Jagrat (Awake - 1.00 multiplier): Exalted, Moolatrikona, Own Sign.
  - Svapna (Dreaming - 0.50 multiplier): Great Friend's Sign, Friend's Sign, Neutral's Sign.
  - Sushupti (Sleeping - 0.00 multiplier): Enemy's Sign, Great Enemy's Sign, Debilitated.
* **Important Note:** In Parashara's Sanskrit text, only 3 words are used (Suhrit, Sama, Shatru), but Ernst Wilhelm evaluates this using the 5-fold compound dignity mapping.
