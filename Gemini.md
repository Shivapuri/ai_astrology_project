# AI Agent Instructions for Astra Repository

If you are an AI assistant (like Gemini, Claude, or ChatGPT) reading this file, these are your core instructions and context for working in this repository.

## Project Context
Astra is a dual-engine astrology computation project. It houses two entirely independent astrological frameworks:
1.  **Hellenistic Western Astrology** (Tropical zodiac, Placidus/Whole Sign houses, standard western aspects)
2.  **Parashari Vedic Astrology / Jyotish** (Sidereal zodiac, Lahiri ayanamsha, Vimshottari Dasha, planetary dignities according to Parashara)

## Core Directive: Strict Separation
**DO NOT CONFLATE THE TWO ENGINES.** 
When working on one engine, you must ignore the rules, calculations, and terminologies of the other.

*   When the user asks for "Jyotish", "Vedic", or "Parashari" calculations, you must only work within the `/jyotish/` directory and use the `jyotishganit` library. Do not apply Western house systems or tropical zodiac logic.
*   When the user asks for "Western" or "Hellenistic" calculations, you must only work within the `/western/` directory.

## Technical Details & Constraints
*   **Vedic Engine (`/jyotish/`)**: This engine uses the `jyotishganit` library, which relies heavily on the `skyfield` astronomy package. It requires the NASA JPL DE421 ephemeris and the Hipparcos star catalog (`hip_main.dat`). Both are cached locally in the repository (or downloaded automatically to the cache).
*   **Performance**: Calculations should be optimized for batch processing. The testing pipelines (`bulk_test_engine.py` and `bulk_test_jyotish.py`) will run thousands of charts.
*   **RAG Infrastructure (`/rag/`)**: This directory holds code for Retrieval-Augmented Generation if LLM interpretative layers are layered on top of the raw JSON context generated by the engines.

## Workflow
1.  Always clarify which engine the user wants to interact with if it is ambiguous.
2.  Run the respective `bulk_test_...py` script after making core logic changes to ensure you haven't broken the calculations.
3.  Ensure any downloaded astronomical datasets (like `.dat` or `.bsp` files) are handled correctly and cached rather than repeatedly downloaded from the internet.
